# nilbot/homebrew-tap

Homebrew tap for nilbot CLI tools and agents.

## Installation

Add this tap:
```bash
brew tap nilbot/tap
```

Install `agents`:
```bash
brew install nilbot/tap/agents
```

Or install directly:
```bash
brew install nilbot/tap/agents
```

## Updating

```bash
brew update
brew upgrade agents
```

| Formula | Description |
|---|---|
| [`agents`](Formula/agents.rb) | Development harness and standalone agent tool |
